The service

OpenREPL lets you run code in interactive REPLs and an editor in your browser. It is free and may change, pause or stop at any time. Current limits include:

  • Each terminal connection lasts up to 60 minutes.
  • Programs run with memory limits and may be stopped when they exceed them.
  • Uploads up to 20 MB, and up to 50 MB of files per workspace.
  • Guest workspaces are deleted about 1 hour after your last visit.
  • Code links are limited per IP address, so a person cannot create very many in a short time.

A code link is a copy of your editor's code that anyone with the link can read, and it stays available until we remove it, so don't put secrets in code you share.
