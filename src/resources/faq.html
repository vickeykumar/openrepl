Getting started

Do I need an account?

No. Start as a guest right away. Guest files are removed an hour after your last visit; sign up free to keep them.

Is it really free?

Yes, you can run code in the browser for free. The source code is open on GitHub. Some extra services may be paid in the future. You can support the project through GitHub Sponsors.

How long does a session last?

Up to 60 minutes per connection. The terminal shows the time left, and one click starts a new session.

Can I use my own files?

Yes. Upload files up to 20 MB, keep up to 50 MB in your workspace, and download it all as a zip.

Can I run it myself?

Yes. Pull the Docker image and run it on your own machine or server. The README on GitHub has the steps.

Sharing

Can someone code with me?

Yes. Press Share and send the link. They see your terminal and editor live and can type along. The link works for the time you choose (a guest up to 1 hour, a signed-in user up to 7 days) and is the same after a reload; End session ends it at once and deletes its data. If you close your editor, they are told you have left and can copy the code to their own editor.

Does a code link last for ever?

No. When you make a code link you choose the last day it works in a calendar: from tomorrow up to a month by default, and a month is picked for you. After that day it says it has expired and the code is removed.

Genie

What can Genie do?

Genie is the AI helper. It reads your editor and terminal, so you can ask why something fails. Its code suggestions show as a diff you accept or reject, with Undo. Open it with Ask Genie or Ctrl+K. Read the Genie guide for the full tour.

Can Genie do a task for me?

Yes, in Agent mode, for signed-in users. Genie writes code, runs it and reads the output step by step. It asks before it changes your editor, runs your program or types in your terminal, and you can press Stop at any time. A task starts with a plan it ticks off, edits one part of a file instead of rewriting it, runs your program after a change and says what it checked. When it uses its steps it pauses and you can Carry on, and Undo this task puts the changed files back. A GENIE.md file in your workspace gives it notes about your project. Genie is told how the editor and the terminal work, so it sees both and can run your code. A small model does Agent mode less well: when you pick one, the panel says so and can switch to the model the site suggests. An empty chat offers a few starter questions. On a phone Genie is the third tab, beside Editor and Terminal.

Are my Genie chats kept?

Yes. Each chat is a tab above the conversation, saved in your own workspace, and a reload brings the same tabs back. Press + for a new chat, switch with a click or Alt+1 to 8, and find closed chats in the list at the end of the strip. Your profile page can stop saving, download all chats as Markdown or delete them. A guest's chats go when the guest workspace is removed.

How many Genie requests do I have?

The line under Genie's message box shows how many requests you have left; click it for the refill rate and your Agent tasks this hour. Requests refill by themselves over time, and signed-in users get more.

Can I keep Genie open beside my code?

Yes. Press the pin in Genie's header and it docks at the right of the workspace, like a side bar, with the editor stacked over the terminal. Drag its left edge to resize it. Press the pin again to let it float. It needs a window at least 1100 pixels wide.

Does Genie keep working if I close its panel?

Yes. An answer or an Agent task carries on while the panel is closed. The Ask Genie button shows that Genie is working, a green dot when the result is ready, and an amber dot when Genie needs your answer. Open the panel to see it, or to press Stop.

Can Genie explain or fix just part of my code?

Yes. Select the code in the editor and right-click it: Explain, Fix problems, Add comments or Write tests. Changes show as a diff you accept or reject.

Can I see how much of Genie I have used?

Yes. Click the requests line at the bottom of the Genie panel: it shows the requests you have left and the tokens used, for your visit as a visitor, or this month and all time when you are signed in.

Can I give Genie a file, a folder or some code to read?

Yes. Right-click a file or folder in the Files panel and choose Add to Genie chat, or select code in the editor and use Add to chat (Ctrl+Shift+L). Each one is a chip above the message box that goes with your next message. Type # in the box to pick a file by name.

Can Genie manage my files?

Yes, in Agent mode. It can open a file in the editor, create, copy, move, rename and delete files and folders in your Files panel. Renaming, moving and deleting are asked about every time.

Practice

Does OpenREPL have DSA practice questions?

Yes. Practice DSA opens with 300+ problems by topic and level. Tick them off as you go, delete the ones you don't want, or press New question to generate more by topic and difficulty. Your progress is saved in your browser, and in your account when you are signed in.

Can Genie help me practise without giving the answer?

Yes. On the Practice page the coach gives up to three hints per question, reviews your solution and states its complexity, and never writes the code for you.

Editor and apps

Why does Debug start paused?

On some servers programs cannot be traced the usual way, so Debug runs yours under QEMU and gdb connects to it. It waits at the first instruction: set your breakpoints, then type c or run. Ctrl+C stops it again.

How big is an app from the App Store?

Each app page shows its size once installed. The store picks the smallest way to make an app (the server's own Ubuntu packages, conda-forge or npm) and removes what a program does not need, such as man pages and test files. A few programs bring their own Python and Perl; their page says so, with the size (about 120 MB for some).

What if an App Store install fails?

The app shows why, and a Try again button. Some failures pass by themselves, so the server tries again a few times. An app that does not exist for a server's CPU type is shown as not available there; an admin can look at it.
