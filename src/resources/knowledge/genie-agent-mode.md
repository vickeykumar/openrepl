In agent mode Genie carries out a task in steps instead of only answering. Signed-in users switch from Chat to Agent beside the Send button; the choice is remembered. Describe a task such as "write a program that prints ten squares and run it". Genie writes in the editor, switches the language, presses Run and reads the output, and works in steps until it is done. Before it changes your editor, switches the language or runs your program it asks: Allow once, Allow for this session, or Deny. Editor changes are shown as a diff and applied only when you accept them. While a task runs, Send becomes a red Stop button. A task has at most 8 steps and counts as one request. It is not offered on the practice page.
