The Files panel is a file explorer for your session's workspace: open it with the folder button beside the language picker. Click a file to load it in the editor; right-click for New file or folder, Rename, Cut, Copy, Paste, Save, Download and Delete. You can upload files up to 20 MB, keep up to 50 MB in total, and download the whole workspace as a zip. A guest workspace is deleted about an hour after your last visit; if you sign in it is kept. The panel shows the space you have left.
