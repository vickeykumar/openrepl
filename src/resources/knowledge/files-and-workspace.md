The Files panel is a file explorer for your session's workspace: open it with the folder button beside the language picker. Click a file to load it in the editor; right-click for New file or folder, Rename, Cut, Copy, Paste, Save, Download and Delete. You can upload files up to 20 MB, keep up to 50 MB in total, and download the whole workspace as a zip. A guest workspace is deleted about an hour after your last visit; if you sign in it is kept. Names that start with a dot (.gitignore, .env, .github) are hidden by default. Right-click a folder and choose Show hidden files (or press Ctrl+Shift+. , Cmd+Shift+. on a Mac) to see them in that folder and everything below it, and Hide hidden files to put them away; the choice is remembered in your browser, and everyone in a shared session sees the same tree. A hidden text file opens and saves like any other; only binary files do not open in the editor. The panel shows the space you have left.
