Steps for a signed-in user (guests are asked to sign in first):
1. Open the Apps button in the top bar, or the full page at /store. Search for the app or pick it from your language's list.
2. Press Install. Apps marked safe install at once. For the rest press Request; an admin decides and you are told. An install takes a minute or two, and the app's page shows its size.
3. When it says Installed, turn its switch On under My apps. It is checked first; if the check fails you can Report to admin.
4. Open a NEW terminal tab: it has the app. A terminal that was open before keeps what it had; run the line shown under My apps there to add it.
5. Use it from your code (the note on using apps by language).

Installed means installed on the server for everyone. The switch changes only your own terminals. You can turn it off at any time, and uninstall an app when nobody else has it on.

If a program says no module named, command not found or cannot find a header, the app is usually not installed or not switched on: check My apps. Genie can offer to install one for you, and asks first.
