Suggest from this list, then use store_suggest. Python and IPython: numpy, pandas, scipy, matplotlib-base (save plots to a file with savefig), scikit-learn, sympy, requests, flask, fastapi, pytest, black, mypy. Large ones need approval: polars, pytorch-cpu (747 MB, 226 MB of memory).

Node and ts-node: lodash, axios, express 4, dayjs, jest, mocha, eslint, prettier, cheerio. Old Node 12: versions are pinned to ones that work.

C and C++: cmake, ninja, cppcheck, clang-format, eigen, fmt, nlohmann_json, catch2, gtest, boost. Their headers are found by the compiler once the app is on.

bash: git, ripgrep, fd, bat, fzf, shellcheck, tmux, vim. Go: gopls, staticcheck. Perl: Mojolicious, Text::CSV. Tcl: tcllib. SQLite: spatialite.

HTML, CSS, JavaScript pages: bootstrap, pico, tailwind, htmx, alpine, react 18, vue, d3, chart.js. They are served from this site to the preview, so a page can load them by address with no internet.

Built in already (never install): Python and Python 2.7, Node.js, TypeScript, Go, OpenJDK, Rust, gcc, g++, cling, Ruby, Perl, Tcl, SQLite, jq and nasm.
