The language picker at the top has a group "Web (shown in the Preview)" with HTML and CSS. They are not languages of the terminal: choosing one sets the editor's mode, puts a starter page in an empty untitled editor, and shows the choice on the picker. The terminal and its language stay as they are.

Run then shows the page in the Preview. With HTML, an untitled editor is saved as index.html (never over a page that exists: index-2.html and so on) and an open .html page is saved and shown. With CSS, the stylesheet is saved (an untitled editor becomes style.css) and the index.html beside it is shown with it; if there is none, a notice says to make one that links to it. Choosing a language of the terminal again takes the picker back to it.
