OpenREPL offers 19 REPLs: C and C++ (cling), Go (gointerpreter and yaegi), Python 3, Python 2.7 and IPython, Rust (evcxr), Java (JShell), JavaScript (an in-browser console), Node.js, TypeScript (ts-node), Ruby, Perl, Tcl, Bash, SQLite, JSON (jq-repl) and Assembly x86 (rappel). Pick a language in the editor and it opens in the workspace, ready to type. If a language you need is missing, use the contact form to ask for it. Each REPL has its own documentation page, linked from the References page.
