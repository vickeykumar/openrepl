The line at the bottom of the Genie panel shows how many requests you have left. Click it for the details: how fast requests refill and when the balance is full again. Below that are the tokens Genie has used, as the models report them: what was sent to the model (your message, the code and terminal text, the conversation) and what the model wrote back, thinking included. Without an account you see the tokens of this visit. Signed in, you see this month and all time, on any device, and Agent tasks are counted step by step. Each answer also shows its own count under it. Only these numbers are kept, never your messages or code. A plan or limit based on tokens is not in place: the limit is still the number of requests.
