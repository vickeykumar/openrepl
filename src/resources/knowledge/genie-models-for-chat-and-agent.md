Chat and Agent mode each remember their own model. Pressing Agent shows the model you last used in Agent mode, or the site's Agent model the first time; pressing Chat brings your Chat model back. Changing one never changes the other.

The site owner chooses which models may be used in Agent mode, because Agent mode needs a model that follows exact instructions and writes valid JSON. The others stay in the list but are greyed with the tag Chat only, and a click says "Model not supported for Agent mode". They still work in Chat. If you press Agent while a Chat only model is on, Genie switches to your Agent pick and says so in one line. Practice questions are written by the Agent model; the New question dialog lists the allowed ones and a change there is for that page only.

Models the owner added can be kept for signed-in users. A guest still sees them, greyed with the tag Sign in, and a click says to sign in to use the complete features of Genie. The owner can also mark an added model as small, which makes Agent mode warn that a stronger one works better.
