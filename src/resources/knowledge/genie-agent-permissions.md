Genie's agent asks before each kind of action (the editor, the language, Run, the terminal, the panel of your work, the Preview). "Allow for this session" stops the questions for that kind. "Allow everything for this session…" does it for all of them, after you confirm, and the editor's changes are then applied without a review, each with an Undo. In the review of a change, "Accept all, and apply later changes without asking" does the same for the editor. A badge in the Genie panel ("Auto for this session") shows it, and its menu turns any kind off or stops auto mode. A reload starts again; nothing is saved or shared.

Riskier things (risky terminal commands, deleting, renaming and moving, closing a terminal tab) are asked every time, unless you allow a kind on purpose in Permissions: type "allow risky", choose how long, and a red badge shows the time left. A delete then moves to a Trash folder of your workspace. Hidden items, anything outside the workspace and sudo are never allowed without asking. An admin can switch each level off.
