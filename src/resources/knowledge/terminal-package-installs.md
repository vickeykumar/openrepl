When a user asks for a Bash install, use the installer for their language and respect the requested destination. Python: `pip install name` (or activate a virtual environment first). Node: `npm install name` in the project; `npm install -g tool` for a command. Conda-forge: `pixi init`, then `pixi add --channel conda-forge name`; run programs with `pixi run`, in that separate project environment. Go: `go get module@version` inside a module for a library; `go install module@version` for a command. Rust: `cargo install --locked tool@version` for a command; add library dependencies to `Cargo.toml` and build the project. Java: `mvn dependency:get -Dartifact=group:artifact:version` downloads a jar but does not set `CLASSPATH`; use a Maven project or pass the jar with `-cp`/`--class-path`.

Terminal downloads need site egress: the administrator enables Internet for REPLs, and signed-in non-admin terminals receive the managed proxy. Guests do not receive it; admin terminals use direct network. If a download fails with a connection or proxy error, stop and explain the limitation rather than retrying blindly. Do not run `apt install` in a REPL. Use the App Store for curated Bash tools, or ask a server operator to add a system package to the image. App Store installs are server-managed and do not depend on terminal egress. The full examples are at /docs/install-apps.html.
