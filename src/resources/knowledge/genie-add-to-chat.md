Genie can read the files and the code you choose, not only the file in the editor. In the Files panel, right-click a file or a folder and choose Add to Genie chat, or drag it onto the chat. In the editor, select code and click the small Add to chat button next to it, or choose Add to Genie chat in the right-click menu, or press Ctrl+Shift+L (Cmd+Shift+L on a Mac). The same works for text you select in the terminal. You can also type # and a few letters of a name in the message box and pick the file or folder from the list. Each one is a chip above the message box; click a chip to open it and the cross to remove it. The dashed chip is the current file: click it to stop Genie reading the editor. Chips go with the next message, and files are read when you press Send. A message takes 8 chips and about 24,000 characters by default: a longer file is cut and its chip turns amber. Binary files, hidden files and folders such as node_modules are never read.
