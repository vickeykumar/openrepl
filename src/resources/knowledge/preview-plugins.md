The preview browser has plugins, listed in the App Store under Browser libraries and plugins. Each one has a switch that only changes your own preview, and a Documentation link.

Ours: the Viewport switcher (phone, tablet, laptop widths), the Outline (the headings and landmarks of the page; click one to scroll there) and the Console (what the page writes, and its calls). They are on by default.

Third party, installed by an admin and then turned on by you: Eruda (console, elements and network inside the page, a good "inspect element") and vConsole (a small console for the page). They are served by this site, so the page's own rules do not change, and they load only in your preview.

If someone suggests developer tools for a page, point to Eruda or the Outline. In a shared session each person has their own plugins on their own pane. A plugin you turn off has no control in the pane.
