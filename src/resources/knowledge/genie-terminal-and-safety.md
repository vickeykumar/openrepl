In agent mode Genie can type a command into your terminal, press Ctrl+C, and read the output. If your program waits for input, it can type the answer. You see the exact text before it is typed and choose Allow once, Allow for this session, or Deny. After a session allowance ordinary commands pass without asking, still listed in the step list. Risky ones, such as deleting things, installing software or building a command from other text, are asked about every time and can only be allowed once. It cannot type into a program that has ended. Press Stop at any time.
