The App Store lets signed-in users add libraries and tools to their terminals. Open it with the Apps button above the editor (a quick dialog; full page: /store) or the command menu. Guests are asked to sign in.

pip install does not work in the terminals (they have no internet). Use the store instead: find the app (for example flask), press Install, then turn its switch On. New terminals have it; an open one keeps what it had. Then python3 can import it.

It is a curated catalogue for each language of the editor, with browser libraries and preview plugins, with filters and a Documentation link on every app. What the server already has is listed as Built in, always on.

Apps marked safe install at once. For the rest, Request (a few a day) and an admin decides; you are told the answer. Installed means installed for everyone, and the switch only changes your own terminals. You can uninstall an app when nobody else has it on. Turning an app on is checked first; if it fails you can Report to admin. Genie can offer to install one too, and asks first.
