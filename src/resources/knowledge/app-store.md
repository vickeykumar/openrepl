The App Store lets signed-in users add libraries and tools (from conda-forge) to their terminals. Open it with the Apps button above the editor (a quick dialog, with a link to the full page at /store) or the command menu entry "App Store". Guests do not have it: sign in first.

pip install does not work in the terminals (they have no internet). Use the store instead: Browse, find the app (for example flask), press Install, then turn its switch On. New terminals have it; to use it in the terminal that is open, press "Use it in my active terminal" under My apps. Then python3 can import it.

Apps on the safe list install at once. Anything else you ask for (Request), and an admin decides; you see the answer in the store. An app is installed once on the server and shared: Installed means installed for everyone, and the switch only changes your own terminals. If an install fails, you see why; press Report to admin and the admin looks at it. Genie can offer to install an app too: it asks you first, and on yes installs it and turns it on. You are told when an admin answers your request.
