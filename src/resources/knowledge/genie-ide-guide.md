The assistant is told how OpenREPL works, so it sees your editor and the last output of your terminal and does not need them pasted. Ask "run my code" or "what does this error mean" and it uses what is on screen.

In Chat it answers and explains. For anything that has to be done, such as running, installing or changing your code, it points you to Agent mode, where it does it.

A small model follows Agent mode less well. When you pick one, the panel says so and offers a Switch button to the model the site suggests, if the admin has set one. Nothing is switched by itself.

An empty chat shows a few starter questions for the mode you are in. Clicking one puts the words in the box so you can change them before you send.
