Select some text in the editor and right-click it to ask about just that part. Explain answers in the Genie panel. Fix problems, Add comments and Write tests show their change as a diff, with Accept and Reject for each part; tests go right after your selection. Each action uses one request. The menu also opens with the Menu key. Hold Shift while right-clicking to get the browser's own menu. On the practice page only Explain is offered.
