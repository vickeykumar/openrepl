When you are signed in, your practice questions, your done marks and the code you write for each question and language are saved in a hidden .practice folder in your workspace. Open the practice page in another browser, or on another computer, sign in, and the list comes back; a question opens with the code you wrote for the language you pick.

The code is saved a moment after you stop typing, and when you leave the page. Signed out, everything stays in this browser only, so clearing the browser's data removes it.
