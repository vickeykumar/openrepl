Type remember, a colon and a sentence in the box, for example remember: indent with tabs. The sentence is added as a note to the notes file of your workspace and every task starts by reading those notes. Edit or delete a note there at any time.

A short tour appears the first time the panel shows. Skip ends it. Typing /tour brings it back.
