A tab with a dot has changes that are not saved. If you reload or close the page while a tab has changes, the browser asks first; choose Cancel to stay, and a bar above the editor offers Save all. Closing a changed tab asks Save, Don't save or Cancel. Save all, in the command menu or on Ctrl+Alt+S (Cmd+Alt+S on a Mac), writes every changed tab. If a page is closed without the question, the unsaved text comes back on your next visit with the choices Save all, Review and Discard all. A sixth file closes the oldest tab without changes first.
