Files you open from the Files panel appear as tabs above the editor, up to five. Choosing a file you already have open just shows it; opening a sixth closes the oldest tab, saving it first if it had unsaved changes. A tab with a yellow dot has changes that are not saved yet. They are kept while you look at another tab, and a copy is kept in your browser so a reload does not lose them. Closing a tab only closes it; the file stays in your workspace. When there are more tabs than room, the strip scrolls sideways and the buttons beside it stay in place. In a shared session everyone sees the same tabs, and choosing a tab shows that file for everyone; only the person who started the session can close tabs.
