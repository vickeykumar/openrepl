title: Open files as tabs in the editor

Files you open from the Files panel appear as tabs above the editor, up to five. Choosing a file you already have open just shows it; opening a sixth closes the oldest tab, saving it first if it had unsaved changes. A tab with a yellow dot has changes that are not saved yet. They are kept while you look at another tab, and a copy is kept in your browser so a reload does not lose them. Closing a tab only closes it; the file stays in your workspace. When there are more tabs than room, the strip scrolls sideways. In a shared session everyone sees the same tabs; a collaborator's close button asks the person who started it to close the tab. A text file bigger than the editor takes opens read-only in a viewer, and a binary file opens there as a hex dump. The + beside the tabs opens an untitled tab, a scratch file that is not in your workspace yet: press Ctrl+S (Cmd+S on a Mac) to name and save it. Closing it with text asks Save, Don't save or Cancel. Right-click a tab (or press Shift+F10 on it) for the Files panel's menu plus Close, Close others and Close all.
