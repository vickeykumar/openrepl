While a task runs, a line above the chat box counts the files it has changed. When it ends, the bar lists them: changed, new, renamed, moved or deleted, including files its scripts made. Click a path to see that file in the editor itself: green bands for what came in, red lines for what went, and a bar to keep the file or put it back as it was. A new file goes to the Trash folder. Either way the row disappears, and the bar goes with the last one.

A file you edited since is left as it is, and says so. A file deleted for good has no copy to put back. Putting back everything asks first.
