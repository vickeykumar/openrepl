Type /add-plugin and open Connections to let Genie use a service as you, such as GitHub. Reads ask once, writes ask each time. Where your admin set up GitHub sign-in you can use Sign in with GitHub; otherwise paste a token. The servers you see are the ones your admin published for you: switch one on, then sign in with your own account (or paste your own token if it has no sign-in). If one is missing, press Ask for a server: an admin decides, and nothing is connected until then. The server keeps your approval of each write: it works once, for that exact call, and ends after two minutes.
