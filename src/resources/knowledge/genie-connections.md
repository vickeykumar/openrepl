Type /add-plugin and open Connections to let Genie use a service as you, such as GitHub. Reads ask once, writes ask each time. Where your admin set up GitHub sign-in you can use Sign in with GitHub; otherwise paste a token. The server keeps your approval of each write: it works once, for that exact call, and ends after two minutes.
