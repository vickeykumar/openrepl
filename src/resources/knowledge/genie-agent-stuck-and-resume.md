The agent tries other ways first. It stops and says it seems stuck only after three failures in a row (a step that worked in between starts the count again), after six steps that changed nothing and printed nothing new, or, in a long stretch of steps, when most are used with nothing changed. No more steps are used while it waits. Choose Keep going (for a task that only looks around), Give a hint (your words go in the chat box), Try with a stronger model (the administrator picks which; it takes over for five steps, then asks whether to keep it), or Stop. A program that exits with an error is not counted.

If the page closes or the connection is lost while a task runs, the chat shows a bar when you return: Resume this task or Discard. Resume starts a new task that looks at the workspace as it is now and carries on with what is left. It is offered for a day.
