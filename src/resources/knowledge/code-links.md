Share, then Create code link, makes a link to a copy of the code in the editor. It opens with that code and its language loaded, and it does not change if you keep editing afterwards. Up to 64 KB of code is stored on the server, and anyone with the link can read it, so do not create one for code that holds passwords or keys. This is different from sharing a live session, which follows what you are doing now.
