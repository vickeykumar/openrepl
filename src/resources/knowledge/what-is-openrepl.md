OpenREPL is a free, open-source online platform for running code in a REPL for many languages, right in the browser. There is nothing to install and no account is needed to start. It is useful for exploratory programming and debugging, for beginners learning a new language, and for developers who want to check a small snippet before putting it into an application. Its source code is open on GitHub. The service is a beta, so it has some limitations.
