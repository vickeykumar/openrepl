REPL stands for Read-Eval-Print Loop. It reads the line you type, evaluates it, prints the result, and waits for the next line. Everything you defined earlier is still available, so you can build on it step by step. There is no compile step and no project to set up, which makes it the fastest way to learn a language one line at a time, try a snippet before it goes into a project, or check an expression.
